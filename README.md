💜 Math Solver

A Simple and Modern Mathematical Learning Tool

Math Solver is a student-focused web application designed to make solving mathematical problems easier and more understandable.

✨ Features

* Equation Solver: Solve mathematical equations.
* Integration Solver: Help with solving integrals.
* Step-by-Step Explanations: Understand how solutions are obtained.
* Examples: Explore example problems.
* History: Review previous calculations.
* Clear Function: Clear the current operation and start again.

🎯 Project Goal

The goal of Math Solver is to support students in learning mathematics by providing a simple, accessible, and user-friendly experience.
